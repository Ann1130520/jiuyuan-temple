## 🛠️ 未來維護與替換教學

### 1. 更換神明 Q 版圖檔（版權為九元宮所有）
請將您的圖片（PNG / SVG / WebP 檔）放入 `images/q_gods/` 目錄中，並開啟 `js/q-cursor.js`，在開頭的 `GOD_CURSORS` 陣列修改路徑與神名即可：
```javascript
const GOD_CURSORS = [
    {
        id: 'leizu',
        name: '九天應元雷聲普化天尊',
        title: '雷部至尊．消災伏魔',
        icon: 'images/q_gods/您的雷祖圖檔.png'
    },
    // ...可依需求增減
];
```

### 2. 替換為九元宮自有的專屬籤詩
開啟 `js/data/qian-data.js`，直接修改裡面的 `window.QIAN_DATABASE` 陣列內容，結構格式皆有範例與中文註解。

### 3. 新增鸞文庫數據
開啟 `js/data/luan-data.js`，在 `window.LUAN_DATABASE` 陣列中新增一筆物件，填寫降筆神尊、日期、詩文與白話淺釋即可立即在網頁上檢索呈現。
